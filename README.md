# 🍔 Spicy Bites - Restaurant & Food Ordering Website

A modern, responsive, and luxury food ordering website built with **HTML5, CSS3, and Bootstrap**. Designed to provide a smooth user experience for food lovers to explore menus, categories, and special offers.

## ✨ Features
* **Responsive Design:** Fully optimized for mobile phones, tablets, and desktops.
* **Hero Carousel:** Stunning banner slides highlighting delicious food items.
* **Interactive Menus:** Organized categories including Fast Food, Italian, and Street Food.
* **Custom Styling:** Enhanced with smooth hover effects, custom scrollbars, and modern UI elements.
* **Bootstrap Framework:** Built using Bootstrap classes for grid layout and components.

## 🚀 Built With
* **HTML5**
* **CSS3**
* **Bootstrap**
* **Font Awesome** (for icons)
